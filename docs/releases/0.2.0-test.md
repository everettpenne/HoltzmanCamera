## What changed in D2

- Four **dynamic launcher shortcuts**: **Photo**, **Selfie**, **Scan**, **Video**.
- Deep links: `holtzman://photo`, `holtzman://selfie`, `holtzman://scan`, `holtzman://video`.
- Each link opens the requested mode directly. A cold start applies the mode before the first camera bind; a warm delivery goes through `onNewIntent`, and the intent data is cleared so the same shortcut works twice.
- `MainActivity` is `singleTop`; shortcut intents use `CLEAR_TOP | SINGLE_TOP`.
- 5 JVM link-parser tests and 1 instrumented shortcut-publication test.

## Still upstream

- Photo, video, QR, Night where available, 4:3 default, tap focus/metering, volume shutter, MediaStore/SAF save and EXIF strip are upstream behaviour, retained.
- Ix remains a debug-only, fail-open pass-through.
- No manual controls, RAW/DNG, Ultra HDR or styles yet.

## Install

```bash
adb install -r app-debug.apk
```

It installs beside GrapheneOS Camera as **Holtzman Camera d**. Dynamic shortcuts appear after the app has been opened once.

## Verify the hook

```bash
adb logcat -s IxJpegDebug
```

A successful capture logs `Ix pass 0.1.0-skeleton: <input> -> <output>` with equal sizes.

## Known limits

- Debug key, debuggable, `.dev` package.
- Dynamic shortcuts are published on launch, not at install time.
- Video recording was not verified on the emulator (its audio HAL failed); photo and all four mode links were verified.
- Manual shortcut/deep link waits for D3.
- The camera cannot be the system/default/lock-screen camera.
- Not tested on a physical Pixel/GrapheneOS device yet.
