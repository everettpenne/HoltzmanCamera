## What changed in D3

- A **MANUAL** mode tab and a live panel with **Shutter**, **ISO**, **Focus** and **White balance** sliders.
- Ranges come from the camera's `CameraCharacteristics`; ISO and exposure are logarithmic, focus is linear in dioptres (∞ at zero).
- **Auto** clears the Camera2 request options; moving any slider re-enters manual.
- ZSL is disabled while manual, because it cannot combine with fixed exposure.
- Manual replaces Video in the four dynamic shortcuts: **Photo · Selfie · Manual · Scan**. `holtzman://manual` is the deep link; `holtzman://video` still opens Video.
- 5 manual-maths JVM tests; 10 JVM and 5 instrumented tests total.

## What it does not do yet

- No RAW/DNG, Ultra HDR or styles.
- White balance is an **approximation** from colour temperature, not a calibrated camera WB.
- No live histogram.
- A camera that rejects Camera2 interop shows "Manual controls are unavailable" and stays in auto.
- Manual still uses the normal JPEG save path; the Ix hook is unchanged.

## Install

```bash
adb install -r app-debug.apk
```

It installs beside GrapheneOS Camera as **Holtzman Camera d**. The four shortcuts appear after the app has been opened once.

## Check on a real phone

1. **Manual tab appears** and the panel is not stuck on "Manual controls are unavailable".
2. Move **Shutter** and **ISO**; exposure should visibly change. **Auto** should restore normal exposure.
3. Move **Focus** from ∞ to a close distance; the preview should hunt/settle. **White balance** should change the tint — judge direction, not colour accuracy yet.
4. Take a manual photo; it should save, and `adb logcat -s IxJpegDebug` should show one equal-size pass.
5. Switch Manual → Camera → Night/Video → Manual; auto should restore cleanly and there should be no green/magenta cast left behind.
6. Check the shortcuts are **Photo, Selfie, Manual, Scan** (no Video shortcut); Video remains reachable from the mode strip.
7. Note whether manual capture feels slower than normal — ZSL is deliberately off.
8. Report the phone model, GrapheneOS version, which controls changed the image, and any crash/log.
