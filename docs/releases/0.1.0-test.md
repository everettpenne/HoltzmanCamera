## What changed in D1

- New application ID `com.everettpenne.holtzman`; debug builds use `.dev` and install beside GrapheneOS Camera.
- Launcher label **Holtzman Camera d**; adaptive aperture icon with a monochrome layer on Android 13+.
- **About Holtzman Camera** in More Settings: product and Ix versions, upstream MIT credit.
- Fixed Glass palette: dark ink/surface, amber accent, Inter, 8/16/24dp corners. Material You wallpaper colours are disabled.
- The user manifest no longer declares `IMAGE_CAPTURE`, `VIDEO_CAPTURE`, `STILL_IMAGE_CAMERA` or the secure variants; `DISABLE_KEYGUARD` and the secure/lock-screen activity entries are gone.
- `minSdk` raised from 29 to 31.

## Same as 0.0.1-test

- Upstream camera: photo, video, QR, modes and settings.
- Ix engine skeleton and adapter.
- Debug-only JPEG pass through `IxJpegDebug`, fail-open.

## Install

```bash
adb install -r app-debug.apk
```

It installs beside GrapheneOS Camera as **Holtzman Camera d**. A release-signed Holtzman build cannot update it without uninstalling first.

## Verify the hook

```bash
adb logcat -s IxJpegDebug
```

A successful capture logs:

```
Ix pass 0.1.0-skeleton: <input bytes> -> <output bytes>
```

The sizes should be equal. Warnings keep the original JPEG.

## Known limits

- Debug key, debuggable, `.dev` package.
- No visible Ix output yet: no styles, RAW, Ultra HDR or manual controls.
- No Sietch handoff, Uno shortcuts/widget or Live Update yet.
- The camera cannot be the system/default/lock-screen camera; those intents are intentionally absent.
- Not tested on a physical Pixel/GrapheneOS device yet; built and tested on an API 36 emulator.
- Desktop launchers may truncate "Holtzman Camera d"; the release label is "Holtzman Camera".
