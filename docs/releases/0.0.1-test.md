# Holtzman Camera 0.0.1-test

**This is a debug test build, not a public release.** It is for trying the Ix JPEG hook on a phone. It uses the upstream camera identity and a debug signing key.

## What it does

- The upstream camera: photo, video, QR, the existing modes and settings.
- The **Ix engine skeleton** and its Android adapter.
- A **debug-only JPEG pass**: after EXIF processing and before the normal write, the JPEG goes through `IxJpegDebug`. It is fail-open; any error keeps upstream's bytes.

The engine is a pass-through, so the photo looks identical. This build proves the hook does not break capture. Styles, RAW and Ultra HDR arrive in D4/D5.

## Install

```bash
adb install -r app-debug.apk
```

It installs beside GrapheneOS Camera as `app.grapheneos.camera.dev`, with the label "Camera d". It will not update a release-signed Holtzman Camera and cannot be updated by one without uninstalling first.

## Verify the hook

Take a photo, then:

```bash
adb logcat -s IxJpegDebug
```

A successful pass logs:

```
Ix pass 0.1.0-skeleton: <input bytes> -> <output bytes>
```

Warnings (for example a skipped style) log `Ix warnings: ...`; the original JPEG is still saved.

## Known limits

- Upstream identity, icon and label; no Holtzman branding yet.
- Debug key, debuggable, `.dev` package.
- No visible Ix output; no RAW, Ultra HDR or styles yet.
- System-camera intents are declared by the upstream manifest but cannot be received by a user-installed app.
- Not tested on a physical Pixel/GrapheneOS device yet.
- Built and tested on an API 36 emulator.
